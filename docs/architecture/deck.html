CARA JALAN

Dikembangkan lokal, dipakai di Kubernetes

Kode yang sama berjalan di dua lingkungan, dengan driver yang menyesuaikan.

Di laptop pengembang
Docker Compose menjalankan PostgreSQL 18 dan Redis 8
Vite dan artisan serve untuk console admin
Migrasi dan seeder referensi FSM dijalankan dari artisan
Seeder demo mengisi data contoh lewat artisan db:seed
PHPUnit dan Pint jadi gerbang sebelum kode masuk
Di server
Cloudflare meneruskan ke nginx Ingress
FrankenPHP dan Octane: satu container web, satu worker antrean
CloudNativePG dan Dragonfly menggantikan PostgreSQL dan Redis lokal
Container worker menjalankan queue:work terpisah dari web
Job migrasi dijalankan sekali saat rilis, bukan saat container boot
GitHub Actions membangun image Docker, membangun kedua APK Android, dan menjalankan suite skenario n8n.
